# Tecnosaude

Dashboard minimalista e clean para gestão de clientes, treinos, dietas e evolução de atletas e pessoas focadas em saúde.

## Visão geral

A primeira versão inclui uma interface responsiva com:

- Dashboard com métricas de clientes, treinos, adesão e consultas
- Gráfico de evolução dos clientes
- Agenda de próximos atendimentos
- Tabela de clientes recentes
- Acesso rápido para treinos, dietas e check-ins
- Navegação por Clientes, Treinos, Dietas, Evolução, Agenda, Mensagens e Configurações
- Modal funcional para cadastrar novo cliente
- Identidade visual Tecnosaude em verde, azul e branco

## Como executar

Abra o arquivo `index.html` no navegador. O projeto é estático e não exige instalação de dependências.

## Próximos passos

A interface está preparada para receber autenticação, banco de dados, geração de PDF, notificações, WhatsApp e integração com um backend.
