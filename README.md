# Tecnosaude

Dashboard minimalista e clean para gestão de clientes, treinos, dietas e evolução de atletas e pessoas focadas em saúde.

## O que já funciona

- Dashboard responsivo com métricas, gráfico e agenda
- Cadastro de novos clientes com persistência local no navegador (`localStorage`)
- Formulário de planos de treino e dieta
- Contador de clientes atualizado após cadastro
- Busca rápida de clientes recentes
- Navegação por Clientes, Treinos, Dietas, Evolução, Agenda, Mensagens e Configurações
- Identidade visual Tecnosaude em verde, azul e branco

## Como executar

Abra `index.html` no navegador. O projeto é estático e não exige instalação de dependências. Os dados criados nesta versão ficam salvos apenas no navegador utilizado.

## Próxima evolução técnica

Para uso real com clientes, será necessário adicionar autenticação, banco de dados seguro, controle de permissões, armazenamento de documentos/fotos, geração de PDF, notificações, WhatsApp e adequação à LGPD. A interface está preparada para receber um backend.
